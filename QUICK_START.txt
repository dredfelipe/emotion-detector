QUICK START GUIDE
=================

Emotion Detection Application
Version 1.0.0

SETUP IN 3 STEPS
================

1. Install Dependencies
   $ cd emotion-detector
   $ pip install -r requirements.txt

2. Configure Watson NLP
   Edit: emotion_detection/emotion_detector.py
   Replace: 'YOUR_API_KEY' and 'YOUR_SERVICE_URL'
   With your IBM Watson credentials

3. Start Server
   $ python server.py
   Open: http://localhost:5000

QUICK TEST
==========

Run Unit Tests:
  $ python -m unittest discover -s tests -p "test_*.py"

Expected Output:
  Ran 7 tests
  OK

API TEST
========

Using curl:
  curl -X POST http://localhost:5000/emotionDetector \
    -H "Content-Type: application/json" \
    -d '{"text": "I am so happy today!"}'

Expected Response:
  {
    "anger": 0.0,
    "disgust": 0.0,
    "fear": 0.0,
    "joy": 0.95,
    "sadness": 0.0,
    "dominant_emotion": "joy"
  }

ERROR TEST
==========

Test Error Handling:
  curl -X POST http://localhost:5000/emotionDetector \
    -H "Content-Type: application/json" \
    -d '{"text": ""}'

Expected Response (400):
  {
    "error": "Invalid text. Please provide non-empty text."
  }

WEB INTERFACE
=============

1. Visit: http://localhost:5000
2. Enter text in the textarea
3. Click "Analyze Emotions"
4. View emotion scores and dominant emotion

TROUBLESHOOTING
===============

Port Already in Use?
  Change port in server.py:
  app.run(debug=True, port=5001)

Watson Credentials Not Set?
  Configure in emotion_detection/emotion_detector.py:
  authenticator = IAMAuthenticator({'apikey': 'YOUR_API_KEY'})
  service_url='YOUR_SERVICE_URL'

Tests Failing?
  Ensure dependencies are installed:
  pip install -r requirements.txt

Permission Denied on setup.sh?
  Make it executable:
  chmod +x setup.sh

PRODUCTION DEPLOYMENT
=====================

Before deploying:
  1. Set debug=False in server.py
  2. Use environment variables for credentials
  3. Deploy behind a reverse proxy (nginx)
  4. Use a production WSGI server (gunicorn)
  5. Enable HTTPS

Example with Gunicorn:
  pip install gunicorn
  gunicorn server:app
