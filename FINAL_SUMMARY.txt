🚀 QUICK START
==============

1. Install Dependencies:
   $ pip install -r requirements.txt

2. Configure Watson (edit emotion_detection/emotion_detector.py):
   Replace: 'YOUR_API_KEY' and 'YOUR_SERVICE_URL'

3. Run Server:
   $ python server.py

4. Open Browser:
   http://localhost:5000

5. Run Tests:
   $ python -m unittest discover -s tests -p "test_*.py"

💾 API EXAMPLES
===============

Request:
  POST /emotionDetector
  Content-Type: application/json
  
  {
    "text": "I am so happy today!"
  }

Success Response (200):
  {
    "anger": 0.0,
    "disgust": 0.0,
    "fear": 0.0,
    "joy": 0.95,
    "sadness": 0.0,
    "dominant_emotion": "joy"
  }

Error Response (400):
  {
    "error": "Invalid text. Please provide non-empty text."
  }

🚀 DEPLOYMENT
=============

Development:
  python server.py
  (runs on localhost:5000 with debug=True)

Production:
  1. Set debug=False in server.py
  2. Use environment variables for credentials
  3. Deploy with Gunicorn:
     pip install gunicorn
     gunicorn server:app
  4. Use reverse proxy (nginx)
  5. Enable HTTPS
