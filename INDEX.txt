💡 API USAGE EXAMPLES
====================

Example 1: Happy Emotion
  curl -X POST http://localhost:5000/emotionDetector \
    -H "Content-Type: application/json" \
    -d '{"text": "I am so happy today!"}'
  
  Response:
  {
    "anger": 0.0,
    "disgust": 0.0,
    "fear": 0.0,
    "joy": 0.95,
    "sadness": 0.0,
    "dominant_emotion": "joy"
  }

Example 2: Error Handling (Blank Input)
  curl -X POST http://localhost:5000/emotionDetector \
    -H "Content-Type: application/json" \
    -d '{"text": ""}'
  
  Response (400):
  {
    "error": "Invalid text. Please provide non-empty text."
  }

See README.md for more examples.
