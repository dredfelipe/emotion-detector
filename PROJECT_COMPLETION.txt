INSTALLATION & SETUP
====================
1. Navigate to emotion-detector directory
2. Install dependencies: pip install -r requirements.txt
3. Configure IBM Watson credentials in emotion_detector.py
4. Run server: python server.py
5. Run tests: python -m unittest discover -s tests -p "test_*.py"

API USAGE
=========
POST /emotionDetector
Content-Type: application/json

Request:
{
  "text": "I am so happy today"
}

Response (200):
{
  "anger": 0.0,
  "disgust": 0.0,
  "fear": 0.0,
  "joy": 0.95,
  "sadness": 0.0,
  "dominant_emotion": "joy"
}

Error Response (400):
{
  "error": "Invalid text. Please provide non-empty text."
}
