USAGE
=====

Installation:
  cd emotion-detector
  pip install -r requirements.txt
  
  (Or use the setup script:
   bash setup.sh)

Run Server:
  python server.py
  
Access Web:
  http://localhost:5000

Run Tests:
  python -m unittest discover -s tests -p "test_*.py"

API Call Example:
  curl -X POST http://localhost:5000/emotionDetector \
    -H "Content-Type: application/json" \
    -d '{"text": "I am so happy!"}'
